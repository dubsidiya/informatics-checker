# Проверяльщик решений по информатике

Ученик получает задачу, пишет код на Python. Если тесты проходят — решение принято. Если нет, система показывает:

- синтаксическую ошибку и строку;
- на каком тесте сломалось;
- логическую или форматную причину;
- ход переменных на упавшем тесте.

Это не нейросеть. Ответ сверяется автотестами, разбор строится по типичным школьным ошибкам и трассировке.

Рабочая ссылка: https://informatics-checker.onrender.com

## Как пользоваться на уроке

1. Ученик открывает сайт, пишет своё имя и выбирает тему или уровень.
2. Пишет код в редакторе с подсветкой и нажимает «Проверить».
3. Учитель открывает `/teacher`, входит по пину и видит, кто что сдал.

Пин учителя задаётся переменной `TEACHER_PIN`. Сейчас по умолчанию: `159753pupil`.

История попыток хранится на сервере, пока инстанс жив. После новой выкладки база может обнулиться.

## Запуск локально

```bash
cd informatics-checker
python3 app.py
```

Открой http://127.0.0.1:8765

Только для разработки. Для класса используй удалённую ссылку, Mac включать не нужно.

## Свои задачи

Добавь объект в `data/problems.json`: условие, примеры, тесты (`stdin` / `stdout`), `topic` и `level`. Скрытые тесты пометь `"hidden": true`.
