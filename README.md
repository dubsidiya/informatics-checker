# Проверяльщик решений по информатике

Ученик получает задачу, пишет код на Python. Если тесты проходят — решение принято. Если нет, система показывает:

- синтаксическую ошибку и строку;
- на каком тесте сломалось;
- логическую или форматную причину;
- ход переменных на упавшем тесте.

Это не нейросеть. Ответ сверяется автотестами, разбор строится по типичным школьным ошибкам и трассировке.

## Запуск

```bash
cd informatics-checker
python3 app.py
```

Открой http://127.0.0.1:8765

Только для локального класса: ученический код выполняется на этой машине. Не выставляй сервер в интернет.

## Свои задачи

Добавь объект в `data/problems.json`: условие, примеры и тесты (`stdin` / `stdout`). Скрытые тесты пометь `"hidden": true`.
